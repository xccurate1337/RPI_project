# Платформа образовательных лекций и спикеров (Lecture Platform)

Учебный проект интерактивной веб-платформы для подбора лекторов, спикеров и просмотра учебных курсов/дисциплин.

---

## 🛠 Стек технологий и версии

- **Язык**: JavaScript (ES2022+ / JSX)
- **Фреймворк**: React `^19.2.8`
- **DOM-библиотека**: React DOM `^19.2.8`
- **Сборщик / Dev Server**: Vite `^8.3.0`
- **Иконки**: Lucide React `^1.47.0`
- **Линтер**: ESLint `^10.10.0`
- **Среда выполнения**: Node.js `>= 18.0.0`, npm `>= 9.0.0`

---

## 🚀 Команды для установки и запуска

### 1. Клонирование репозитория
```bash
git clone https://github.com/xccurate1337/RPI_project.git
cd RPI_project
```
*(Если проект находится во вложенной папке `lecture-platform`, перейдите в неё: `cd lecture-platform`)*

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск в режиме разработки (Hot Module Replacement)
```bash
npm run dev
```
После запуска проект откроется по адресу: `http://localhost:5173` (или указанному в терминале порту).

### 4. Сборка для production
```bash
npm run build
```
Собранные статические файлы будут сохранены в папку `dist/`.

### 5. Предпросмотр production-сборки
```bash
npm run preview
```

### 6. Запуск линтера
```bash
npm run lint
```

## 🗄 Где лежат данные и как устроен роутинг

### 1. Данные (Data Layer)
- **`src/data/lecturers.js`**:
  - Содержит массив объектов `LECTURERS` (10 лекторов).
  - У каждого объекта есть: `id`, `name`, `gender`, `education`, `experience`, `degree`, `photo`, массив `disciplines` (название дисциплины и список тем `topics`), а также варианты `tariffs` с ценами.
- **`src/data/partners.js`**:
  - Содержит информацию о партнерах платформы (ICL, Татнефть, ссылки, логотипы и описания).

### 2. Роутинг (Routing)
- В проекте используется компонентный роутинг на основе состояния в `src/App.jsx`.
- Текущая страница управляется через React State: `const [activeTab, setActiveTab] = useState('home');`.
- Доступные табы / страницы:
  - `'home'` — `HomePage` (Главная страница)
  - `'partners'` — `PartnersPage` (Партнеры)
  - `'about'` — `AboutPage` (О нас)
  - `'lecturers'` — `LecturersPage` (Лекторы с возможностью фокуса/скролла к конкретному `selectedLecturerId`)
  - `'courses'` — `CoursesPage` (Каталог дисциплин с кликабельным переходом к преподавателю)
- Навигация осуществляется через верхнее меню `Header.jsx`, а также через внутренние кнопки переходов (например, «Найти лектора» или клик по преподавателю из каталога курсов).
